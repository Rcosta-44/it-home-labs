# Lab 03 – Windows System Administration

## Project Overview

This hands-on lab demonstrates practical Windows system administration, endpoint management, user account configuration, and foundational IT support skills.

The objective was to develop experience managing a Windows workstation using native administrative tools and applying concepts commonly used in enterprise IT environments.

## Lab Environment

| Component | Configuration |
|---|---|
| Hardware | Dell laptop |
| Operating System | Windows 11 |
| Environment | Physical workstation |
| Account Types | Administrator and standard user |

## Tools and Technologies

- Computer Management
- Microsoft Management Console (MMC)
- Local Users and Groups
- Windows Settings
- Windows Update
- Windows Services
- Task Manager

## Lab Objectives

- Create and manage local user accounts.
- Understand administrator and standard user privileges.
- Apply the principle of least privilege.
- Navigate native Windows administrative utilities.
- Inspect system services and startup configurations.
- Review operating system updates.
- Develop practical endpoint administration skills.

## Technical Procedures

### 1. Local User Account Management

- Created local accounts for administrative and standard employee use.
- Configured account types and reviewed assigned privileges.
- Explored the differences between administrator and standard user access.
- Practiced separating administrative responsibilities from everyday user activities.

### 2. Computer Management and MMC

- Accessed Windows Computer Management.
- Explored Microsoft Management Console and administrative snap-ins.
- Reviewed local users, groups, and system management utilities.
- Practiced navigating centralized Windows administration tools.

### 3. Windows Services Management

- Accessed the Windows Services console.
- Reviewed running and stopped services.
- Examined automatic, manual, and disabled startup types.
- Developed an understanding of how background services support operating system functionality.
- Considered the potential impact of modifying essential system services.

### 4. Windows Update and Patch Management

- Reviewed Windows Update settings.
- Checked operating system update status.
- Examined the importance of patch management for system stability and security.
- Developed familiarity with routine workstation maintenance.

### 5. System Resource Management

- Explored Windows system resource utilization.
- Reviewed running processes and background applications.
- Developed familiarity with workstation performance monitoring.

## Security Considerations

Throughout this lab, emphasis was placed on:

- Principle of least privilege (PoLP)
- Separation of administrative and standard user accounts
- Operating system patch management
- Safe management of system services
- Endpoint security awareness
- Minimizing unnecessary administrative access
