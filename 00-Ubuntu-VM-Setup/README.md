# Ubuntu Server Virtual Machine Setup

**Goal:** Create a safe, isolated environment for practicing Linux IT administration.

**Environment:** Apple Silicon Mac, UTM virtualization, Ubuntu Server ARM64, terminal/CLI. The Ubuntu guest has approximately 1.6 GiB RAM and a root filesystem of approximately 14 GiB according to lab outputs.

**Work performed:** Set up an Ubuntu Server virtual machine; logged in with an administrative account; checked hostname, networking, disk usage, and memory; used the terminal for later labs.

**Evidence:** See `screenshots/` for setup and installation screenshots. Some screenshots show intermediate configuration or setup screens, not necessarily final settings.
